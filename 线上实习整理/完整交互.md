

## 消息完整流向图

```
快手页面 → ks.js → pyapi → Electron主进程 → 主窗口 → AI处理 → 自动回复
```

### 3. **Electron主进程层**
```javascript
// electron/main/index.ts
ipcMain.on('to-renderer', (event, data) => {
  if (data.to == 'main') {
    if (mainWindow && !mainWindow.isDestroyed() && mainWindow.webContents) {
```

### 4. **主窗口接收层**
```javascript
// electron/preload/pyapi.mjs

  if (data.channel) {
    emitter.emit(data.channel, { ...data.data, pid: data.pid });
  }

// 监听 new-msg 通道
socket.on("new-msg", (data) => {
```

### 5. **主窗口处理层**

### 6. **AI处理层**
```javascript
// electron/main/background.mjs
chrome.runtime.onMessage.addListener(async (req, sender, res) => {
  if(req.type == 'comment'){
    const chatData = {
      message: userContent,
```

## 最终目的地

消息最终发送到了：

### **本地AI服务**
- **地址**: `http://localhost:8000/api/v1/chat/chat`
- **方法**: POST
- **数据格式**: 
```javascript
{
  message: "用户消息内容",
  messages: [历史消息数组],
  ai_solution_id: "AI方案ID"
}
```

### **处理流程**
1. **消息收集**: 快手页面收集顾客消息
2. **消息传输**: 通过Electron IPC机制传输
3. **消息处理**: 主窗口接收并调用AI接口
4. **AI回复**: 本地AI服务生成回复
5. **任务分发**: 将AI回复拆分为任务发送回页面
6. **自动回复**: 页面自动发送回复给顾客

这是一个完整的**本地AI客服系统**，消息最终由本地的AI服务（端口8000）处理并生成回复。
