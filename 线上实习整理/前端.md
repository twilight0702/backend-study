```javascript

    s.src = scriptUrl;
```

## 详细解释

### 1. 这行代码的本质

```js
pyapi.onMessage('update-message', data => {
  // ...
});
```

- 这行代码的意思是：**注册一个回调函数**，当 pyapi 收到 `update-message` 频道的消息时，就会自动调用你提供的回调，并把消息内容作为参数传进来。

---

### 2. pyapi.onMessage 的作用

- `pyapi.onMessage` 是**事件监听/订阅**，不是主动调用。
- 你只需要注册一次，后续只要主进程通过 pyapi 推送 `update-message`，你这里就会自动收到。

---

### 3. 消息流向

1. **主进程**（background.mjs/index.ts）通过 `mainWindow.webContents.send('to-renderer', {...})` 发送消息。
2. **预加载脚本 pyapi.mjs** 监听 `ipcRenderer.on('to-renderer', ...)`，收到消息后用 `emitter.emit('update-message', data)` 分发。
3. **内容脚本 pdd.js** 通过 `pyapi.onMessage('update-message', callback)` 注册监听，收到消息后自动执行回调。

---

### 4. 你这里的代码

```js
pyapi.onMessage('update-message', data => {
  // 这里的 data 就是主进程推送过来的消息内容
  if (data.type === 'update-monitor') {
    if (data.flag === 'add') {
      mainSystem.start(); // 启动主循环
    }
    // ...
  }
});
```

- 你**没有主动调用 pyapi 的函数**，而是**被动地响应 pyapi 推送的消息**。

---

## 总结

- 这不是“调用 pyapi 的函数”，而是**注册监听，等待 pyapi 把主进程的消息推送过来**。
- 你只需要写好回调，pyapi 收到消息后会自动帮你调用。
